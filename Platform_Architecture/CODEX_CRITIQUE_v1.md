# Codex critique of PLATFORM_PLAN_v1 (2026-07-08)

Verdict: **RESHAPE** (do not ship the all-5 static MVP as the first serious prototype).

Key findings:
- **(a) All-5 static MVP is too broad.** It becomes a polished sales demo for an OS the 2-person team cannot deliver in Phase 2 (auth, tenancy, persistence, submissions, AlphaSense wiring, entitlement are the hard parts). Risk = setting 5-year-workspace expectations before any module proves repeat usage beyond a workshop walkthrough.
- **(b) One threaded case is coherent but risky as the main proof.** Anchor x Polaris looks connected because data is curated, not because workflows work on messy real data; it hides that Patent Exchange is a stub and Ideas Funnel has no real submission/funding behavior.
- **(c) Shell-first is the wrong order.** A 5-year timeline spine only matters if real module events roll up onto it. Start from the two substantive assets, then have the home report THEIR real milestones/gaps/targets/outreach.
- **(d) 5-year access is heavy for a first-time institutional buyer** - asks belief in a long-horizon system before habit/retention/ownership are proven. Modules 2/3/5 imply different buyers/rhythms (course leaders, innovation owners, patent collaborators, corp dev, integration teams); one 5-year entitlement raises "who owns it after the course?"
- **(e) Biggest ignored risk = category confusion.** Mixes exec-ed + innovation tracking + patent commercialization + target sourcing + integration before establishing the wedge. Sharpest tension: capability-building infrastructure (Learning/Ideas/Patent) vs transaction-execution tooling (Target Sourcing/Deal Integration) - different urgency, users, data sensitivity, willingness to pay.

Recommended reshape (2-module MVP):
1. Target Sourcing + Deal Integration, connected by ONE capability-gap -> deal-thesis workflow.
2. Reuse ARS page only after clearly separating acquirer-readiness from target-attractiveness (currently conflated).
3. Workspace home = thin exec dashboard reporting only REAL events from those two modules.
4. Learning + Ideas = course-origin metadata feeding the capability gap, not full modules/pages.
5. Patent Exchange out of MVP (or a single "future" tile, not a stub pretending to be product).
